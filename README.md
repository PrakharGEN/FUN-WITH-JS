# 🎮 Fun with JavaScript

A collection of **interactive JavaScript projects** built using HTML, CSS, and Vanilla JS.  
Perfect for learning, experimenting, and having fun while developing core web development skills!

---

## 🧩 Projects Included

| Project | Description |
|--------|-------------|
| 🎯 **Chrome Dinosaur Game** | A clone of the Chrome offline Dino runner game. |
| 🆔 **College Card Generator** | Generates student ID cards dynamically. |
| 🖼️ **Custom Image Resize** | A tool to resize images manually with draggable dimensions. |
| 🎲 **Dice Game** | Roll the dice in this simple two-player game. |
| 🥁 **Drum Kit** | A virtual drum kit playable with your keyboard. |
| 📐 **Image Resizing Tool** | Resize and crop images, perfect for social media. |
| 🌍 **Planet Selling Webpage** | A fun and creative sci-fi themed landing page. |
| 🔂 **Simon Game** | Classic memory game built with JavaScript. |
| ✊✋✌️ **Rock Paper Scissors** | Simple rock-paper-scissors game. |
| ❌⭕ **Tic Tac Toe** | Two-player Tic Tac Toe game in JS. |
| ⏰ **Clock** | A real-time clock using JS. |
| ⏳ **Countdown Timer** | A countdown timer for tracking events. |
| ✍️ **Signature Maker** | Create your signature using mouse or touch and download it. |
